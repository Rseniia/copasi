# Анализ ASD(3).cps

Расчёты выполнены через Python 3.12.10 окружения проекта и copasi-basico. Исходная модель не изменена: SHA-256 до и после `ae5fed7ce6b64b67c4267fed1e620398d24ed67504b9c28676b92ffbdd443bea`. Скрипт воспроизведения: `../analyze_asd.py`. Результаты относятся к исходной реализации, включая обнаруженные ошибки; подбор новых параметров не выполнялся.

## Единицы, переменные и начальные условия

Время — с; количество — моль; объём — л; концентрация M = моль/л. Один фиксированный компартмент Soma объёмом 1e-12 л (1 пЛ). Глобальных параметров, assignment- и ODE-переменных нет; 12 кинетических параметров локальные. GSH, GSSG, H2O2 определяются реакциями; остальные виды фиксированы.

| Вид | Начальная концентрация, M | Тип |
|---|---:|---|
| GSH | 0.0015 | reactions |
| GSSG | 2e-8 | reactions |
| H2O2 | 0 | reactions |
| H2O | 55.5 | fixed |
| NADP | 2e-6 | fixed |
| NADPH | 5e-5 | fixed |
| gammaGluCys | 2e-6 | fixed |
| O2 | 3e-5 | fixed |
| H2O2_ext | 1 | fixed |

**H2O2_ext = 1 M = 1000 мМ = 1 000 000 мкМ.** Это не 1 мкМ и не 1 мМ. В файле начальное значение хранится как примерно 6.02214e11 частиц; деление на число Авогадро и 1e-12 л подтверждает 1 M. Вид находится в Soma, отдельного внешнего компартмента нет: это математически бесконечный резервуар с неизменной концентрацией. Начальный приток g·H2O2_ext = 0.1 M/с.

## Реакции и кинетика

Обозначения в уравнениях ниже: S=GSH, D=GSSG, H=H2O2, N=NADPH, C=gammaGluCys, E=H2O2_ext. Скорости v — M/с. COPASI `(reaction).Flux` возвращает моль/с; в CSV дополнительно приведены `v_*_M_s`, полученные делением на объём.

| Реакция | Стехиометрия |
|---|---|
| GPx | 2 GSH + H2O2 → GSSG + 2 H2O |
| GR | GSSG + NADPH → 2 GSH + NADP |
| GS | gammaGluCys → GSH |
| CAT | 2 H2O2 → 2 H2O + O2 |
| Flux | H2O2_ext → H2O2 |

Все реакции помечены irreversible. GPx и CAT имеют ожидаемые коэффициенты в укрупнённой схеме. GR не содержит протона; GS не содержит глицина и энергетических кофакторов, поэтому полную элементную/зарядовую сбалансированность этой схемы подтвердить нельзя. Молекулярных формул и зарядов в модели нет. Фиксированные NADPH, NADP, gammaGluCys и прочие виды предполагают внешнее поддержание и не позволяют исследовать истощение кофакторов.

### GPx

Формула в файле: `Vmax_GPx*H2O2*GSH^2/(Km_H2O2*GSH^2 + Km_GSH*H2O2 + GSH^2*H2O2)`.

**Ошибка mapping:** формальный H2O2 связан с GSH, формальный GSH связан с H2O2. Реально вычисляется:

`vGPx = Vmax_GPx*S*H^2/(Km_H2O2*H^2 + Km_GSH*S + H^2*S)`.

Vmax_GPx=0.001; Km_H2O2=1e-5; Km_GSH=0.001.

Для размерной однородности этой формы Vmax должен иметь M/с, Km_H2O2 — M, а **Km_GSH — M²**, поскольку он складывается с квадратом концентрации. Если 0.001 задумывалось как обычный Km в M, выражение некорректно; исправление требует выбора формы кинетики или определения параметра как квадрата константы. Число 0.001 само по себе не доказывает размерность M. Mapping дополнительно меняет физический смысл этих констант.

### GR

`vGR = Vmax_GR*D*N/(Km_GSSG*N + Km_NADPH*D + D*N)`.

Vmax_GR=0.0004 M/с; Km_GSSG=0.0001 M; Km_NADPH=9.1e-6 M. Mapping соответствует названиям; выражение размерно однородно при указанных единицах.

### GS

`vGS = Vmax_GS*(C/Km1 + C^2/(a*Km1*Km2))/(1 + 2*C/Km1 + C^2/(a*Km1*Km2))`.

Vmax_GS=0.1 M/с; Km1=6.3e-5 M; Km2=0.000164 M; a=0.1 (безразмерный). C фиксировано, поэтому vGS=0.00333696046427 M/с постоянно. Нет обратной связи по GSH и нет удаления общего глутатиона.

### CAT

Формула в файле: `k_Cat*H2O2*[CAT]`; k_Cat=176. В списке аргументов функции есть только k_Cat и H2O2: отдельный вид или параметр CAT и его концентрация **не заданы**. В полученном численном расчёте `vCAT/H = 176 с⁻¹` при H>0, т.е. эффективный дополнительный множитель равен 1. Это наблюдаемая численная интерпретация данной версии, а не подтверждённая концентрация фермента. Нужно явно определить, является ли k_Cat эффективной константой первого порядка (с⁻¹) или произведением бимолекулярной константы (M⁻¹ с⁻¹) на концентрацию CAT (M). Фактор 2 в расходе H2O2 уже задаётся стехиометрией: dH/dt содержит -2vCAT.

### Flux

`vFlux = g*(E-H)`; g=0.1 с⁻¹. Размерно однородно. Формула может дать отрицательное значение при H>E, хотя реакция помечена необратимой; на рассчитанной траектории этого не происходит. Следует согласовать обратимый транспорт и знак реакции в будущей редакции.

Загрузка и `compileIfNecessary()` успешны; COPASI не сообщает ошибок validity. Успешная компиляция не удостоверяет биологическую корректность или смысл единиц локальных констант.

## Исходный Time-Course

Использован сохранённый горизонт 0–100 с, 1000 интервалов, 1001 строка, детерминированный LSODA, начальные значения из файла. Базовые допуски rtol=1e-6, atol=1e-12. Дополнительно: 0–0.1 с с шагом 0.0001 с для быстрого перехода; 0–1000 с; проверка с rtol=1e-9, atol=1e-15.

| Показатель | t=0 | t=100 с |
|---|---:|---:|
| GSH, M | 0.0015 | 0.3351960461 |
| GSSG, M | 2e-8 | 2.016859974e-8 |
| H2O2, M | 0 | 0.0002840099953 |
| GSH/GSSG | 75 000 | 16 619 698 |
| vGPx, M/с | 0 | 8.065517e-8 |
| vGR, M/с | 7.998109e-8 | 8.065517e-8 |
| vGS, M/с | 0.0033369605 | 0.0033369605 |
| vCAT, M/с | 0 | 0.0499857592 |
| vFlux, M/с | 0.1 | 0.0999715990 |

На всех сохранённых точках концентрации неотрицательны, NaN/Inf нет; GSSG положителен, отношение определено всюду. Это проверка выходных точек, не всех внутренних шагов интегратора. Расхождения после ужесточения допусков: GSH ≤4.31e-14 M, GSSG ≤2.16e-14 M, H2O2 ≤3.83e-12 M. Сообщения COPASI касаются только отсутствия встроенного report filename; результаты независимо экспортированы в CSV.

Балансовые уравнения:

```
dS/dt = -2*vGPx + 2*vGR + vGS
dD/dt = vGPx - vGR
dH/dt = -vGPx - 2*vCAT + vFlux
d(S+2D)/dt = vGS = 0.00333696046427 M/s > 0
```

Следовательно, полного стационарного состояния нет при этих постоянных входах. Плато H2O2 и GSSG не означает стационарности модели. На 100 с dS/dt=0.00333696 M/с, а на 1000 с S=3.338460464 M. Этот вывод следует непосредственно из стехиометрии, не зависит от неуспеха численного поиска стационарного состояния.

Биологическая интерпретация: рост GSH до 335 мМ за 100 с несовместим с обычным клеточным масштабом. В первичном исследовании [Intracellular glutathione pools are heterogeneously concentrated](https://pmc.ncbi.nlm.nih.gov/articles/PMC3830055/) рассматривается клеточный диапазон 0.5–15 мМ, с зависимостью от компартмента. Это ориентир, не универсальная граница для всех тканей. Экспериментальная работа [A ratiometric fluorescent probe…](https://pubs.rsc.org/en/content/articlehtml/2020/sc/d0sc02889d) использует 1 мМ внешнего H2O2 и наблюдает уменьшение GSH; здесь внешняя концентрация в 1000 раз выше. Прямое количественное сравнение клеточных систем без выбора ткани и условий некорректно.

## COPASI Sensitivities

Подзадача **Time Series**, эффект — три изменяемые концентрации, причины — все 12 локальных кинетических параметров; secondary cause=Not Set. Горизонт 100 с, rtol=1e-9, atol=1e-15; Delta factor=0.001, Delta minimum=1e-12. Рассчитывается локальная чувствительность **конечного состояния**, не средняя чувствительность всей траектории:

`Sij = (pj / xi(100)) * ∂xi(100)/∂pj`.

Ранжирование — евклидова норма трёх безразмерных коэффициентов. Положительный знак означает рост конечной концентрации с параметром; отрицательный — уменьшение. При относительном изменении параметра на 1% локально ожидается изменение концентрации примерно Sij процентов.

Для GSH важнее GS.Vmax_GS и GS.Km1; для GSSG — Flux.g, CAT.k_Cat, затем группа GPx/GR; для H2O2 — Flux.g и CAT.k_Cat. Различия около единицы у нескольких параметров малы: их нельзя интерпретировать как надёжно различные уровни важности. При Delta factor=0.0001 максимальное изменение масштабированного коэффициента 0.00270; ведущие группы устойчивы, тонкий порядок близких коэффициентов несущественен.

Дополнительно исследованы все начальные концентрации: для H2O2_ext коэффициенты GSH≈-2.41e-7, GSSG≈2.0004, H2O2≈1.0000. Для фиксированного резервуара это чувствительность к постоянно поддерживаемой концентрации. gammaGluCys существенно влияет на GSH (≈1.0373). Нулевой масштабированный коэффициент для исходно нулевого H2O2 не доказывает отсутствия абсолютной чувствительности.

Все три основные таблицы чувствительности непустые и конечные. Ненормированные производные находятся в `sensitivities_unscaled.csv`, COPASI summary в `sensitivities_summary.csv`, полное ранжирование — `sensitivity_ranking.csv`.

## Вывод для следующего этапа

Исходная модель вычислительно исполнима, но пока не пригодна для обоснованного подбора биологически правдоподобных параметров: необходимо исправить mapping GPx, определить размерность Km_GSH и трактовку CAT, проверить предполагаемый масштаб H2O2_ext, а также обеспечить баланс синтеза и удаления общего глутатиона либо явно ограничить исследование коротким переходным режимом. При положительном постоянном vGS изменение только GPx/GR/CAT/Flux не создаст полного стационарного состояния.

Полученные ранги описывают исходную модель с её ошибками. После исправления структуры их необходимо пересчитать. Для установления приемлемых диапазонов параметров нужны выбранный тип клеток, условия воздействия и целевые экспериментальные диапазоны GSH, GSSG и H2O2; эти три этапа сами по себе не идентифицируют единственный набор кинетических констант.
